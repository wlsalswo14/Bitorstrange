PAIN POINT (어떤 사람들의 어떤 불편함인가?) ⚠️
"비트코인 얼마 갈까?"라는 헛된 예측과 파산
  • • 단일 가격 예측의 치명적 함정: 개인 투자자들은 인플루언서나 점쟁이식 차트 예측에 의존하다가 급락장(Black Swan)에서 공포에 질려 패닉셀하고 파산합니다.
  • • 과학적 리스크 관리 도구 부재: 시장에는 "오른다/내린다"를 점치는 소음만 넘쳐나고, "어떤 폭락이 닥쳐도 내 자산 한도(-25%)를 지켜주는 전략"을 사전에 검증할 도구가 없습니다.
  • • 사후 확증 편향: 과거 데이터에만 끼워맞춘 일반 백테스트는 실제 예측 불가능한 미래 시장에서 무력화됩니다.
INNOVATION (기존 방식과 무엇이 다른가?) 💡

02. 심사 기준: 스폰서 제품 활용 (Sponsor Product Usage) ⭐
Daytona SDK [필수 & 최우선] Nosana GPU Serving [가산점]

미래를 생성하고(Nosana), 미래를 직접 살아본다(Daytona)

완벽히 격리된 샌드박스와 분산 GPU AI가 결합하여 타협 없는 대규모 금융 스트레스 테스트 환경을 완성했습니다.

스폰서 활용 1 ⭐ [가장 중요 - 필수] Daytona SDK
Daytona: 8개 평행 전략 격리 실험실
• 어디에 썼는가? (Where)
10만 개 미래 시나리오에서 8가지 투자 전략(HODL, DCA, 80% Rebalancing, Volatility-Targeting 등)을 각각 독립 격리 환경에서 실행하는 '평행 전략 실행 엔진'에 적용했습니다.
• 왜 썼는가? (Why)
대규모 금융 백테스트는 수많은 분기와 상태를 연산하므로 로컬 환경에서는 메모리 간섭 및 상태 오염이 발생합니다. Daytona SDK를 통해 8개의 TypeScript 격리 샌드박스를 단 수십 밀리초 만에 동시 생성하여 오차 없는 안전한 병렬 실행 런타임을 확보했습니다.
const sandbox = await daytona.create({ language: 'typescript' });
const res = await sandbox.process.codeRun(code); // 8개 샌드박스 동시 병렬 실행
스폰서 활용 2 ⭐ [가산점 필수 항목] Nosana GPU Network
Nosana: 오픈소스 AI Council & 시뮬레이션
★ 가산점 항목: "노사나(Nosana) 분산 GPU를 통해 모델을 서빙했습니다."
• 어디에 썼는가? (Where)
오픈소스 거대언어모델 qwen/qwen3.8-27b를 Nosana 분산 GPU에 서빙하여 시장 분석·뉴스·거시경제·위험 진단 4대 AI Council을 실시간 구동했습니다.
• 왜 썼는가? (Why)
단순 정적 통계의 한계를 극복하고, 거시 변동성과 폭락 위험도를 반영한 100,000개의 몬테카를로 미래 시나리오 파라미터(Drift, Volatility, Seed)를 초고속 추론하기 위해 Nosana GPU를 필수 채택했습니다.
